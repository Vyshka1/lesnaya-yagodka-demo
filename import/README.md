# Импорт каталога в Tilda

В папке лежит всё, что нужно, чтобы залить 70 товаров в каталог Tilda за один заход.

| Файл | Что это |
|---|---|
| `catalog-tilda.csv` | Каталог в формате Tilda: 70 товаров, 8 разделов |
| `catalog-woocommerce.csv` | Тот же каталог в формате импортёра WooCommerce |
| `tilda-store.css` | Стили для магазинных блоков Tilda (T951, T706) |
| `img/*.jpg` | Фотографии товаров, 700 × 700, JPEG |

## Как импортировать

1. В Tilda открыть **Каталог товаров → Импорт → Загрузить CSV**.
2. Выбрать `catalog-tilda.csv`. Разделитель — точка с запятой, кодировка UTF-8.
3. На шаге сопоставления колонок проверить, что Tilda распознала `SKU`, `Title`,
   `Category`, `Price`, `Quantity`, `Photo`. Колонки `Characteristics:*`
   станут характеристиками товара.
4. Запустить импорт. Фотографии Tilda подтягивает сама по ссылкам из колонки `Photo`.

## Что внутри CSV

| Колонка | Источник |
|---|---|
| `SKU` | внутренний артикул прототипа (P01, Z14, V03 …) |
| `Title` | название с вкусом; у пастилы ягода стоит первой |
| `Category` | раздел каталога |
| `Description` | состав, короткой строкой под названием |
| `Text` | описание товара |
| `Price` | цена, ₽ |
| `Quantity` | остаток; 0 — нет в сезоне |
| `Photo` | прямая ссылка на JPEG в этом репозитории |
| `Characteristics:Вес` | фасовка |
| `Characteristics:Состав` | состав |
| `Characteristics:Срок годности` | срок хранения |
| `Characteristics:Пищевая ценность` | ккал, белки, жиры, углеводы |
| `Mark` | «Не в сезоне» у позиций с нулевым остатком |

## О чём помнить

- **Ссылки на фотографии временные.** Они ведут на GitHub Pages этого прототипа.
  После импорта убедитесь, что Tilda перенесла файлы к себе на `tildacdn`,
  и только потом отключайте репозиторий.
- **Данные из прототипа, а не из учётной системы.** Цены и остатки собраны
  с действующего сайта и с тех пор могли измениться — перед публикацией
  каталог стоит сверить с владельцами.
- **Подарочные наборы в файл не вошли** — они убраны из прототипа.
- **Состав и пищевая ценность** для части позиций выведены по аналогии
  внутри линейки. Всё, что печатается на этикетке, должен подтвердить производитель.

## Импорт в WooCommerce

`catalog-woocommerce.csv` — разделитель запятая, кодировка UTF-8.

1. **Товары → Импорт → Выбрать файл**.
2. Сопоставление колонок WooCommerce определит само: `SKU`, `Name`,
   `Regular price`, `Stock`, `Categories`, `Images`, `Attribute N`.
3. Картинки подтягиваются по ссылкам из колонки `Images` — на медленном
   хостинге импорт лучше запускать частями.

Характеристики приходят атрибутами: вес, состав, срок годности,
пищевая ценность. Они помечены как глобальные, чтобы по ним потом
можно было строить фильтры каталога.
