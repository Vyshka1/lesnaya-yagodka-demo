# Лесная ягодка — демонстрационный концепт

Концепт интернет-магазина для ООО «Лесная Ягодка» (Псковская область).

**Это неофициальная работа.** Автор не связан с компанией и не имеет доступа к её сайту.
Концепт сделан как предложение по улучшению и передаётся владельцам бесплатно.

## Что внутри

Одна самодостаточная страница `index.html` (~4 МБ): вся вёрстка, данные и изображения
вшиты в файл, внешних зависимостей нет, кроме шрифтов Google Fonts.

* 72 товара с реальными ценами, составами, сроками годности и остатками — данные взяты
  с действующего сайта lesnaya-yagodka.ru
* каталог с фильтрами по категории, цене и составу, переключением плотности сетки
* карточка товара, корзина, оформление заказа
* конструктор подарочного набора
* подписка на возврат сезонных позиций и отзывы

## Важно

* Заказы не принимаются и никуда не отправляются: формы ничего не сохраняют,
  оплаты нет. Об этом написано на самой странице.
* Подписки и отзывы, оставленные на демо, сохраняются только в браузере посетителя.
* Фотографии принадлежат ООО «Лесная Ягодка» и использованы, чтобы показать концепт
  владельцам. Сайт закрыт от индексации (`robots.txt`, `noindex`).
* Телефон и почта намеренно не указаны — их нужно взять с действующего сайта.

## Локальный запуск

Файл открывается двойным щелчком, сервер не нужен.
